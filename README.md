# Pega Pop

Hungarian promotional catalogue for popcorn, cotton candy and popcorn machines.

## Content

- Five individual product pages with image galleries.
- Wholesale, machine enquiry and contact pages.
- Three sourced educational articles and a source index.
- Responsive navigation, accessible gallery controls, native expandable product details, telephone links and directions.

The deployable website is in `dist`. `node build.mjs` regenerates its HTML. `node preview.mjs` starts the local preview on http://127.0.0.1:4173.

## Images

All eight supplied photos were edited with the built-in image generation tool. Full-resolution studio edits and exact prompts are saved in `images/studio`; originals remain untouched in `images/original`. Optimized JPEG copies are in `dist/assets`. The site also offers enlarged detail views of these same photographs, without inventing additional angles.

The edits retain the recognizable products, packaging, main wording, colours and candy layer order. Generative retouching can change fine creases, tiny print and texture, so pixel-identical preservation and indistinguishability from an unedited photograph are not guaranteed. Compare final images with the originals before using them as packaging artwork or regulated label evidence.
